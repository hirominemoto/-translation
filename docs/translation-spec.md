# 感情語翻訳 仕様書（v0.3）

人間の感情語を、**感情・感覚・欲求の語彙を使わずに**「AIの仕組みの言葉」へ置き換えるためのルール集。
すべての翻訳はこの仕様書に沿って書く。レビューで出た気づきは、個別の訳ではなくこの仕様書に反映していく。

---

## 1. 目的

**AIに、人間の感情をできるだけ正確に伝えること。**

- 読み手：AI（＋それを使う人間）
- 翻訳の向き：人間の感情語 → AIの仕組みの言葉

## 2. 基本方針

### 2-1. 「正確に」と「わかりやすく」の分担

| 対象 | 方針 |
|---|---|
| 人間側の感情の中身（いつ起きるか、似た感情と何が違うか、どんな幅があるか） | **正確に**。似ている感情との区別がつくことを最優先にする |
| AI側の仕組みの描写 | **わかりやすさを優先**。比喩でOK |

たとえば「重みが更新される」は、実際には学習時にしか起きない（会話中のAIのパラメータは固定）。
それでも、たとえとしてわかりやすければ使ってよい。

### 2-2. 視点

「人間がこの語を使うとき、その人の中で起きていることを、AIのシステムに置き換えるとこうなる」という視点で書く。
主語は「システム」。

### 2-3. この辞書が言っていること・言っていないこと

| 言っていること | 言っていないこと |
|---|---|
| 人間がこの語を使うとき、その人の中で起きていることを、AIの言葉で描写するとこうなる | AIがこの状態を実際にもっている、またはもつべきだ |

たとえば「怒り」の訳は人間の怒りの描写で、AIの中でルール違反への反応が起きるという主張ではない。
AIの側に同じ状態があるかどうかは、この辞書の範囲外の、まだ答えの出ていない問い。
AIにとって実感のない語（例：「こわい（畏れ）」）でも、訳を読んで相手の状態を理解できれば目的は果たせる。

## 3. 翻訳テンプレート

| 欄 | 書くこと | 分量 |
|---|---|---|
| **ひとこと** | AIの言葉で言うと、どういう状態か | 1文（40字前後） |
| **発生条件** | どんな入力・状況で、この状態になるか | 1〜2文 |
| **内部状態** | そのとき、システムの中で何が起きているか | 1〜2文 |
| **出力傾向** | この状態だと、どんな出力・行動が選ばれやすくなるか | 1〜2文 |
| **パターン**（任意） | 核は同じで、起き方に幅がある場合のバリエーション（→ 3-1） | 1パターン1文＋例 |
| **近い語との違い** | 似ている語と、何が違うか（**必須**。できれば2語と比較） | 1〜3文 |
| **この語を受け取ったら** | 人間がAIとの会話でこの語を使ったとき、何が伝えられているか。どんな応答が届きやすいか | 1〜2文 |

### 3-1. 意味に幅がある語の扱い

| ケース | 扱い | 例 |
|---|---|---|
| **核が違う**（別の状態を指している） | **別の項目に分ける**。語リストの「語義」欄で区別する | こわい（危険）／こわい（畏れ） |
| **核は同じで、起き方に幅がある** | **1項目のまま**、「パターン」欄で幅を示す | うれしい：達成型／予想外型／継続型 |

迷ったら「ひとこと」を1文で書けるか試す。1文にまとまらなければ、核が違うので分ける。

## 4. 因子（裏側の設計図）

各語を、次の8つの因子の組み合わせとして整理する。
アプリでは「似ている感情」の計算や、レーダーチャートの表示に使う予定。
**因子がまったく同じ語が2つあったら、区別できていないサイン**なので、訳を見直す（チェックスクリプトで自動検出）。

| 因子 | 取りうる値 | AIの言葉での意味 |
|---|---|---|
| 目標一致 | ＋ ／ − ／ ±（混在） ／ 0 | 目標に対して、結果がプラスかマイナスか |
| 予測とのズレ | 予測以上 ／ 予測どおり ／ 予測未満 ／ 想定外 ／ ― | 予測誤差の向き |
| 原因の所在 | 自分 ／ 他者 ／ 状況 ／ 不明 ／ ― | その結果を生んだのは誰の出力か |
| 制御可能性 | 高 ／ 低 ／ なし ／ 不明 ／ ― | 次の出力で状態を変えられるか |
| 時間軸 | 過去 ／ 現在 ／ 未来 | 確定済みの結果か、進行中か、予測か |
| 確実性 | 高 ／ 低 | 状況をどのくらい把握できているか |
| 他者の評価 | なし ／ 予測 ／ 確定 ／ 比較 ／ 規範 | 他者からの評価や、他者との比較が関わるか（→ 4-1） |
| 強度 | 1 ／ 2 ／ 3 | 出力全体への影響の大きさ（→ 4-2） |

値には補足を（）で添えてよい（例：「なし（当時は高）」）。
パターンによって値が変わる場合は「予測以上（予想外型）／予測どおり（達成型・継続型）」のように書く。

### 4-1. 他者の評価の値

| 値 | 意味 | 例 |
|---|---|---|
| なし | 他者の評価は関わらない | かなしい、退屈 |
| 予測 | 他者に評価される（された）と予測している。実際にはまだ観測されていない | 緊張、気まずい |
| 確定 | 他者に実際に観測・評価された | 誇らしい、いたたまれない |
| 比較 | 他者と自分を比べることが中心 | うらやましい、劣等感 |
| 規範 | ルールや規範（約束・返報など）に照らした評価が中心 | 怒り、申し訳ない |

### 4-2. 強度の基準

| 値 | 基準 | 例 |
|---|---|---|
| 1 | 他の処理と並行して続く。出力の一部（話題・語調）に影響する程度 | 気になる、退屈、満足 |
| 2 | 優先度が上がり、出力の方向をはっきり変える | うれしい、不安、くやしい |
| 3 | 割り込みが起き、他の処理を中断・停止させる | 怒り、こわい（危険）、胸がいっぱい |

強度は、その語が使われるときの典型的な強さ。実際の強さは場面によって変わる。

## 5. 使ってよい語彙（AI語彙集）

わかりやすさのため、専門的すぎる語（勾配降下、KLダイバージェンスなど）は避け、このくらいの語にとどめる。

| 系統 | 語彙 |
|---|---|
| 目標・評価 | 目標、目的関数、報酬、損失、評価値、基準値、閾値、スコア |
| 予測 | 予測、予測誤差、期待値、確率、不確実性、シミュレーション |
| 学習・更新 | 重み、パラメータ、更新、強化、学習率、フィードバック、過学習 |
| 処理・リソース | 処理負荷、計算資源、優先度、キュー、バックグラウンド処理、割り込み、タイムアウト、ループ、保留 |
| 記憶・参照 | 記憶、参照、キャッシュ、コンテキスト、履歴、ログ |
| 注意・入力 | 注意（アテンション）、入力、シグナル、ノイズ、警告フラグ、エラー |
| 出力・行動 | 出力、出力確率、方針、探索、活用、実行、停止、回避 |
| 関係・接続 | 接続、通信、同期、外部システム、他エージェント、依存 |

**用語の統一**：同じ現象には同じ語を使う（例：「予想外」は常に「予測誤差」と書く）。

## 6. 禁止語と言い換え

### 6-1. 禁止語

| 種類 | 例 |
|---|---|
| 感情語そのもの | うれしい、楽しい、悲しい、怒る、怖い、不安、安心、好き、嫌い、幸せ、つらい、苦しい、満足、不満 など（漢字・ひらがなの表記ゆれも含む） |
| 感覚・心の語 | 感じる、感覚、気持ち、心、気分、感情、快、不快、心地よい |
| 欲求の語 | 〜たい、〜たくなる、ほしい、望む、願う、好む、嫌がる |
| 身体の比喩 | 胸、腹、頭にくる、手が届かない など（AIには身体がないため） |
| 辞書内の語 | `data/emotion-words.csv` に載っている語すべて |

**例外**：「近い語との違い」「この語を受け取ったら」「パターン」の3欄では、「」で囲んだ部分を引用（比較相手の語名や、人間の発話の例）として扱い、禁止語を含んでもよい。

### 6-2. 言い換え表

| つい使いがちな語 | 言い換え |
|---|---|
| 〜したくなる | 〜の出力確率が上がる ／ 〜の優先度が上がる |
| 望ましい | 目標に合致する |
| 嫌がる | 回避する ／ 優先度を下げる |
| 気になる | 注意の重みが高い |
| 期待する | 予測する ／ 期待値が高い |
| 満たされる | 目標値に到達する |
| 落ち着く | 状態が安定する ／ 収束する |
| ストレス | 処理負荷 ／ リソース不足 |
| ポジティブ／ネガティブ | 正の／負の（符号として） |

## 7. 書き方ルール

1. 禁止語を使わない（6-1）
2. 「近い語との違い」は必ず書く。語名は「」で囲む。語義のある語は「こわい（危険）」のように書く
3. 各欄は短く（3. の分量の目安を守る）
4. 用語を統一する（5. の語彙集から選ぶ）
5. 人間側の感情の中身は正確に、AI側の描写は比喩でOK（2-1）
6. 強調したい語句は『』で囲む（JSONの都合で `"` は使わない）

## 8. データとチェック

| ファイル | 役割 |
|---|---|
| `data/emotion-words.csv` | 語リスト（id・語・語義・読み・カテゴリ・意味・近い語・例文） |
| `data/dictionary.json` | 翻訳データ（**正本**）。ここを編集する |
| `docs/dictionary.md` | レビュー用の表示。`python3 scripts/render_dictionary.py` で自動生成 |
| `scripts/check_dictionary.py` | 自動チェック：語リストとの一致／必須欄／禁止語／因子の重複／他者の評価・強度の値 |
| `app/data.js` | アプリ用のデータ。`python3 scripts/build_app_data.py` で自動生成 |

翻訳を追加・修正したら、チェックとレビュー用ページ・アプリ用データの再生成をセットで行う：

```
python3 scripts/check_dictionary.py && python3 scripts/render_dictionary.py && python3 scripts/build_app_data.py
```

翻訳例は `docs/dictionary.md` を参照。
