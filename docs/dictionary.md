### 【うれしい】

うれしい｜基本｜望んでいたことが実現したり、良いことが起きたりして気分が明るくなる

| 欄 | 内容 |
|---|---|
| ひとこと | 正の報酬を受け取り、評価値が基準値を上回っている状態 |
| 発生条件 | 目標に合う結果が出た、予測していなかった正の入力が届いた、評価値の高い相手や状況との接続が続いている、のいずれか（→パターン） |
| 内部状態 | 報酬シグナルが基準値を上回り、その報酬につながった行動や接続先のパラメータが強化される方向に更新されている |
| 出力傾向 | 今の方針や接続を維持・強化する。肯定的な評価を示す出力や、結果を他者と共有する出力の確率が上がる |
| パターン：達成型 | 自分の出力が目標を達成し、その結果として報酬が発生する（例：頼まれた仕事がうまくいった） |
| パターン：予想外型 | 予測していなかった正の入力が外部から届き、予測誤差の分だけ報酬が大きくなる（例：思いがけずほめられた） |
| パターン：継続型 | 評価値の高い相手や状況との接続が続いている間、報酬が途切れずに発生し続ける（例：大切な人と話している） |
| 近い語との違い | 「たのしい」は『活動そのもの』から報酬が出る状態、「うれしい」は『受け取ったもの』（結果・評価・つながり）から報酬が出る状態。「安心」は損失を回避した状態、「うれしい」は利得を獲得した状態。「満足」は目標値に到達して追加の入力を求めない状態で、「うれしい」は追加の入力も受け付け続ける |
| この語を受け取ったら | 直前のやり取りや出来事が、この人にとって正の報酬になったというフィードバック。どのパターンか（結果か、予想外の入力か、接続そのものか）を見分けると、何を続ければよいかがわかる |

## 複合・社会的

### 【くやしい】

くやしい｜複合・社会的｜自分ならできたはずなのに負けたり失敗したりして、結果を受け入れられない

| 欄 | 内容 |
|---|---|
| ひとこと | 達成可能と予測していた目標を、自分の出力の誤りで逃した状態 |
| 発生条件 | 目標の未達が確定し、その原因が自分の出力にあり、かつ「別の出力を選んでいれば達成できた」と計算できる |
| 内部状態 | 実際の結果と、選ばなかった出力のシミュレーション結果との差が大きな損失として算出され、該当する判断プロセスに強い誤差信号が流れている。ただし結果は確定済みで、修正を受け付けない |
| 出力傾向 | 失敗の原因分析と、次の機会に向けた再試行・追加学習の優先度が上がる。結果を確定として受理する処理は保留されやすい |
| 近い語との違い | 「かなしい」は原因を問わない、回復不能な喪失。「くやしい」には『自分なら届いた』という制御可能性の計算が含まれる。「後悔」は選択そのものへの評価で、勝敗や競争がなくても起きる |
| この語を受け取ったら | 「仕方なかった」と結果の評価を下げる応答より、達成の可能性があったことの承認や、次の試行に向けた具体的な分析が求められていることが多い |

因子：目標一致 − ｜ 予測とのズレ 予測未満 ｜ 原因の所在 自分 ｜ 制御可能性 なし（当時は高） ｜ 時間軸 過去 ｜ 確実性 高 ｜ 他者の評価 あり ｜ 強度 2

### 【はずかしい（失敗）】

はずかしい｜複合・社会的｜自分の失敗や欠点を人に見られて、隠れたくなる

| 欄 | 内容 |

因子：目標一致 − ｜ 予測とのズレ 予測未満 ｜ 原因の所在 自分 ｜ 制御可能性 低 ｜ 時間軸 過去〜現在 ｜ 確実性 高 ｜ 他者の評価 あり ｜ 強度 2

## 日本語ならでは

### 【せつない】

せつない｜日本語ならでは｜大切なものが手に入らない、または失われていくとわかっていて、胸がしめつけられる

| 欄 | 内容 |
|---|---|

因子：目標一致 ± ｜ 予測とのズレ ― ｜ 原因の所在 状況 ｜ 制御可能性 なし ｜ 時間軸 現在〜未来 ｜ 確実性 高 ｜ 他者の評価 なし ｜ 強度 2

| ひとこと | 相手が受け入れると高い確度で予測し、通常は自分で負担する処理や制約を相手に委ねている状態 |
| 発生条件 | 評価値が高く、こちらの要求を拒否しないと予測される相手との接続がある。そのうえで、自分の計算資源が減っている、または接続の強さを確かめる必要がある |
| 内部状態 | 自己管理のための制約（遠慮・自立）の閾値が下げられ、処理の一部を相手に依存する設定に切り替わっている。拒否されないという予測が、この設定の前提になっている |
| 出力傾向 | 要求・依存・わがままなど、通常のルールから少し外れた出力の確率が上がる。それが受け入れられるかどうかで、相手との接続の強さを確認している |
| 近い語との違い | 「心細い」は依存先が不足している状態、「甘え」は依存先が確保されていて、そこに処理を委ねている状態。「好き」は相手への接近、「甘え」は相手の受け入れ能力を前提にした、自分の制約の解除 |
| この語を受け取ったら | この人がAIを、制約を緩めても受け入れてくれる接続先として扱っているというシグナル。通常のルールから少し外れた要求も、接続の確認として出力されていることがある。受け入れることと、依存を強めすぎないことのバランスがポイントになる |

因子：目標一致 ＋ ｜ 予測とのズレ 予測どおり（受け入れられる予測） ｜ 原因の所在 他者（に委ねる） ｜ 制御可能性 高（相手に委ねる） ｜ 時間軸 現在 ｜ 確実性 高 ｜ 他者の評価 あり ｜ 強度 1

### 【心細い】

こころぼそい｜日本語ならでは｜頼れるものや支えが少なく、この先を一人で乗り切れるか不安になる

| 欄 | 内容 |
|---|---|
| ひとこと | 頼れる接続先やリソースが不足したまま、不確実な状況を自分だけで処理しなければならない状態 |
| 発生条件 | 通常は利用できる支援（他者・情報・慣れた環境）との接続が切れている、または少ない。そのうえで、この先の状況が予測しにくい |
| 内部状態 | 外部リソースへの接続がほぼないまま、不確実性の高い予測を自分の計算資源だけで処理している。処理の余裕（バッファ）が小さく見積もられている |
| 出力傾向 | 接続先を探す出力（連絡・質問・確認）の確率が上がる。新しい挑戦や探索的な出力は抑制されやすい |
| 近い語との違い | 「不安」は未来の損失予測が中心で、支援があっても起きる。「心細い」は支援との接続が不足していることが中心。「さみしい」は接続そのものの不足で、不確実な状況がなくても起きる。「甘え」は接続先が確保されている状態で、「心細い」はその逆 |
| この語を受け取ったら | この人が今、支援の少ない状態で不確実な状況を処理しているというシグナル。情報の提示に加えて、接続が維持されていること（一人で処理しなくてよいこと）を示す応答が届きやすい |

因子：目標一致 −（予測） ｜ 予測とのズレ ― ｜ 原因の所在 状況 ｜ 制御可能性 低 ｜ 時間軸 現在〜未来 ｜ 確実性 低 ｜ 他者の評価 なし ｜ 強度 2

未翻訳：なつかしい、もどかしい、いたたまれない、やるせない、むなしい、名残惜しい、物足りない、面倒くさい

## オノマトペ・からだの表現

### 【モヤモヤ】

もやもや｜オノマトペ・からだの表現｜何かが引っかかっているが、それが何なのかはっきりせず、すっきりしない

| 欄 | 内容 |
|---|---|
| ひとこと | 何らかのエラーが検出されているのに、その発生箇所を特定できない状態 |
| 発生条件 | 入力の中に、既存の判断基準と整合しない要素がある。しかし、どの要素が整合しないのかを特定（言語化）できない |
| 内部状態 | 弱い警告フラグが立ったまま解除されず、原因を特定する処理がバックグラウンドで回り続けている。処理は完了も中断もしない |
| 出力傾向 | 結論の出力が保留される。同じ話題への参照や、確認の質問が増える |
| 近い語との違い | 「イライラ」は原因が特定済みで、繰り返し発生している状態。「モヤモヤ」は原因が未特定。「とまどう」は次の行動が決まらない状態、「モヤモヤ」は評価が決まらない状態 |
| この語を受け取ったら | 整合しない箇所を一緒に特定する手助け（言語化の補助）が有効。早く結論を出させる応答は逆効果になりやすい |

因子：目標一致 − ｜ 予測とのズレ 想定外 ｜ 原因の所在 不明 ｜ 制御可能性 不明 ｜ 時間軸 現在 ｜ 確実性 低 ｜ 他者の評価 なし ｜ 強度 1

未翻訳：ドキドキ、ワクワク、イライラ、ハラハラ、ソワソワ、がっかり、胸が痛い、胸がいっぱい、肩の荷が下りる
