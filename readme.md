## AI用感情語翻訳ツール

AIとコミュニケーションをとるための翻訳ツール。

人間の感情語を、感情・感覚・欲求の語彙を使わずに「AIの仕組みの言葉」へ置き換えて（因数分解して）、**AIに人間の感情をできるだけ正確に伝える**ことを目指す。

### 進め方

| STEP | 内容 | 成果物 | 状態 |
|---|---|---|---|
| 0 | 翻訳ルールを決める | [`docs/translation-spec.md`](docs/translation-spec.md) | たたき台 v0.1 |
| 1 | 感情語を集める（まず50語） | [`data/emotion-words.csv`](data/emotion-words.csv) | たたき台 |
| 2 | 翻訳する（試訳10語 → レビュー → 残りを翻訳 → 自動チェック → 最終レビュー） | `data/dictionary.json` | 未着手 |
| 3 | アプリにする（静的Webアプリ） | `app/` | 未着手 |

### 方針

- 人間側の感情の中身は**正確に**、AI側の仕組みの描写は**わかりやすさ優先**（比喩OK）
- 感情語を「目標一致」「予測とのズレ」「原因の所在」などの因子に分解し、似た感情との違いをはっきりさせる
